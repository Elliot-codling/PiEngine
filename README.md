# PiEngine

## What is PiEngine

A 2D cross-platform graphics library. It is not a game engine, like Godot or many others. But it does more than a standard graphics library. 
Powered using Pygame, this feature packed engine allows you to create a game in Python instead of starting from scratch.

## Why not just write in Pygame

You can and you don't have to use PiEngine at all. The reason of this project is so that you can harness the power of Pygame while abstracting the complexities of making everything from scratch. Many functions have been created for you such as: window management, sprites, audio, io and more!

## What is the goal of this project

We do not really have a goal or a stopping point. This is a fun project to allow users to easily create python games for fun.
However, there are some things that will not be done. Mainly a GUI, this is a script-only engine and everything must be created from code.
You are welcome to fork the project and create your own GUI.

## Supported Platforms & Requirements

All platforms are supported. As long as you have a python environment setup, you are good to go.
However, there are some minimum requirements for Python and Pygame.
- Python 3.6+
- Pygame 2.0+

## How to get started

1. Download the latest version of PiEngine by cloning from the 'stable' branch or going to the releases tab to download the project.
2. Open up '__main__.py' to start the project.
